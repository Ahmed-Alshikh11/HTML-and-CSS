# HTML-and-CSS

This repository contains two major projects:

---

## 🎬 Bootstrap Movie Website
A full Bootstrap-based movie showtime website featuring:
- Navbar with bookmark links  
- Jumbotron  
- Bootstrap card deck  
- Movie posters, descriptions, and showtimes  
- Info-colored pill badges  
- Clean, responsive layout  

---

## 🎨 Portfolio Website (HTML + CSS)
A colorful, unique portfolio website demonstrating:
- Centered image with CSS filter + rounded edges  
- Styled table with borders, padding, and colored header  
- Text over images  
- Fixed navbar with hover effects  
- Two-column layout  
- Paragraph hover effects  
- Image overlay fade  
- Autoplay muted looping video  
- Video with text overlay  
- Styled footer  

---

Both projects were created as part of a web development learning module.
